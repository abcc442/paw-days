# Paw Days｜AI 宠物生活与数字陪伴（概念原型）

面向宠物主人的产品概念项目，围绕宠物成长记录、基于宠物档案的养护参考、数字小窝与实体—数字收藏联动，完成产品设计与可交互演示。

## 在线体验入口

- **官网**：`index.html` — 产品宣传网站，内置 App 演示弹窗。
- **直接体验 App**：`demo.html` — ROOM / CLUB / DROP / PAW ID 的交互原型。
- **首屏预览**：`preview.png`。

**注意：** 当前为产品设计和交互概念演示。真实 AI 模型、知识检索、支付/商品权益核验和线上兽医服务尚未接入，相关页面为模拟流程。

## 部署到 GitHub Pages

1. 创建名为 `paw-days` 的 GitHub 仓库（可根据需要更名）。
2. 将 `index.html`、`demo.html`、`preview.png` 上传到仓库**根目录**，一起提交。
3. 仓库进入 **Settings → Pages**，选择 **Deploy from a branch**，分支选择 `main`、目录选择 `/ (root)`，保存。
4. 等网站发布后，官网入口通常为 `https://<你的GitHub用户名>.github.io/paw-days/`，独立原型为同一域名下的 `/demo.html`。
5. 在简历中**只放官网链接**，把 `demo.html` 作为网站内的直达体验入口或附在案例说明中。

## 不使用 Git 的快速部署

Cloudflare Pages 支持 Direct Upload：在 Workers & Pages 中创建 Pages 项目，选择上传静态文件，把本文件夹内容上传即可。请确保 `index.html` 位于部署根目录。

## 项目定位与面试说明

- 我做了什么：产品定位、PRD、功能优先级、体验流程、AI 应用场景设计、多页面原型、品牌官网。
- AI 在哪里：照片/视频到宠物数字形象的概念链路；宠物生活素材整理为成长事件；结合已有档案查找养护参考。
- 产品差异：不是一次性的图片生成，而是记录长期积累、可追溯的宠物档案与持续更新的数字空间。
- 商业化思路：平台限定宠物好物与对应数字同款绑定，领取后放进数字小窝。
